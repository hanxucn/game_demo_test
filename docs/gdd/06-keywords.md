# 06 · 关键词体系

> 状态：**已定**。关键词是内容产能的"词汇表"——AI 批量产卡时按关键词组合，即可保持风格一致与强度可控。

## 1. 关键词与状态的关系

| 概念 | 定义 | 例子 |
|---|---|---|
| **关键词** | 卡牌**自带**的常驻特性，写在卡面上 | 盾兵自带「架盾」 |
| **状态** | 对局中被**施加**的临时效果，可被驱散 | 被施加「震慑」 |

**桥接规则**：部分关键词会**授予对应状态**（只要条件满足）：

| 关键词 | 授予的状态 | 条件 |
|---|---|---|
| 架盾 | 架盾 | 该人物位于**前军**时 |
| 先攻 | 先攻 | 永久 |
| 奇袭 | 奇袭 | 直到其发起攻击 |
| 武圣 | 武圣 | 直到免疫一次伤害 |
| 结阵 | 结阵 | 攻击时动态判定 |

## 3. 关键词详解

### 3.1 忠义

| 项 | 内容 |
|---|---|
| 效果 | 该人物卡阵亡时，触发其描述的亡语效果 |
| 触发时机 | 死亡结算后（见 `10-skills-statuses.md` 结算时机表） |
| 叠加 | 不叠加；每张卡只有一个忠义效果 |
| UI | 图标：白色羽扇 / 灰色描边 |
| 设计注意 | 亡语不能过强，否则"送死流"会成为唯一解 |

### 3.2 遗计

| 项 | 内容 |
|---|---|
| 效果 | 该人物卡阵亡时，其控制者抽 1 张牌 |
| 与忠义的关系 | 是忠义的**固定形态**，独立成关键词以便定价与批量产卡 |
| 触发时机 | 同忠义 |
| 设计注意 | 抽牌价值约 3 属性点，故关键词价值记为 −2（已扣除"需要死亡"的概率折扣） |

### 3.3 疾行

| 项 | 内容 |
|---|---|
| 效果 | 入场当回合即可发起普通攻击 |
| 不提供 | 额外攻击次数（本回合仍只能攻击 1 次，除非同时有「连击」） |
| 触发时机 | 入场即获得，永久 |
| 设计注意 | 疾行 + 高攻 = 强突进；需控制属性预算 |

### 3.4 架盾

| 项 | 内容 |
|---|---|
| 效果 | 敌方任何普通攻击必须先攻击该人物（可跨列） |
| **生效条件** | **仅当该人物位于前军**；位于后军则失去架盾 |
| 优先级 | 高于同列限制、高于「神射」 |
| 对主将 | **不阻挡**对主将的攻击 |
| 破盾 | 击杀该人物；或使用谋臣计略/战法/事件（计略伤害无视架盾） |
| UI | 图标：盾牌；位于后军时图标置灰 |
| 设计注意 | 架盾保护的是**将士**，不是主公；主将由阵型保护 |

### 3.5 武圣

| 项 | 内容 |
|---|---|
| 效果 | 免疫一次伤害（无论来源） |
| 消耗 | 免疫一次后关键词消失 |
| 触发时机 | 伤害结算前判定 |
| 与护甲的区别 | 武圣对**该人物卡**生效；护甲只对**主将**生效 |
| 设计注意 | 是路线 B（高属性无技能）的"抗解"手段 |

### 3.6 神射

| 项 | 内容 |
|---|---|
| 效果 | 可攻击**任意列**的敌方人物卡，无需同列 |
| 限制 | 仍须遵守架盾；攻击主将仍需满足"所在列两排皆空" |
| 不受影响 | 不受"被自己人挡住"限制（可从后军越排攻击） |
| 设计注意 | 神射的价值是"跨列施压"，不是"无视嘲讽" |

### 3.7 连击

| 项 | 内容 |
|---|---|
| 效果 | 每回合可发起 2 次普通攻击 |
| 攻击次数 | 每张人物卡每回合默认 1 次，连击提升为 2 次 |
| 结算 | 两次攻击分别结算伤害与反击 |
| 设计注意 | 连击 + 高攻 = 极高爆发，属性必须显著下调 |

### 3.8 饮血

| 项 | 内容 |
|---|---|
| 效果 | 该人物造成伤害时，为己方主将恢复等量生命 |
| 治疗上限 | 主将生命不超过 30 |
| 不与护甲互动 | 不增加护甲 |
| 触发 | 普通攻击、主动技造成的伤害均触发 |
| 设计注意 | 饮血在持久战中价值极高，需控制属性 |

### 3.9 奇袭

| 项 | 内容 |
|---|---|
| 效果 | 不能被敌方指定为攻击目标 |
| 失去条件 | 该人物发起攻击后立即失去奇袭 |
| 不受保护 | 仍会被群体伤害（AoE）、事件卡、随机目标效果命中 |
| UI | 卡面半透明 + 潜行图标 |
| 设计注意 | 奇袭 + 高攻 = 无法被先手处理，属性需下调 |

### 3.10 先攻

| 项 | 内容 |
|---|---|
| 效果 | 攻击时先结算自己的伤害；若目标阵亡，则不受反击 |
| 触发 | 仅普通攻击；反击方不享受先攻 |
| 双方都有先攻 | 同时结算，均不享受"目标阵亡则免反击"的优待 |
| 设计注意 | 先攻对"高攻低血"单位价值最大 |

### 3.11 结阵

| 项 | 内容 |
|---|---|
| 效果 | 若同列或左右相邻列存在 ≥1 名友方**步兵**，本次普攻 +1 伤害 |
| 判定时机 | 每次攻击时动态判定（不改变面板攻击力） |
| 相邻范围 | 同列（前后）+ 左右相邻列（共最多 5 格） |
| 不叠加 | 无论有几个相邻步兵，都只 +1 |
| UI | 满足条件时卡牌发光 + 图标高亮 |
| 设计注意 | 步兵是"集群推进"兵种，鼓励铺阵 |

### 3.12 无双

| 项 | 内容 |
|---|---|
| 效果 | 该人物发起普通攻击时，不受到目标的反击伤害 |
| 不等于先攻 | 先攻是"抢在反击前结算"；无双是"根本不挨反击" |
| 不提供 | 不免疫主动技/战法/事件造成的伤害 |
| 设计注意 | 价值最高的关键词之一，通常只出现在顶级武将上 |

## 4. 关键词组合的定价规则

多个关键词同时出现时，**总价值 = 各关键词价值之和 × 0.9**（折扣系数，避免组合过强）。

例：`疾行（−1.5）+ 先攻（−1）= −2.5 × 0.9 = −2.25`，向上取整为 −2.5。

## 5. 关键词与 UI 的对应

| 优先级 | 显示方式 |
|---|---|
| 最多 3 个关键词 | 卡面显示图标 |
| 超过 3 个 | 显示前 3 个 + "+N"，点击查看 |
| 失去条件的关键词（如后军的架盾、已消耗的武圣） | 图标置灰并加删除线 |
