# 09 · 羁绊系统

> 状态：**草案**（机制已定，具体羁绊与人物名单待策划确认）

## 1. 为什么需要羁绊

产品的核心卖点之一是"**各个不同人物的特点组合**"。关键词解决"单卡辨识度"，羁绊解决"**组合价值**"：

- 让玩家有收集与构筑的动力（"我要凑齐刘关张"）；
- 让同一张卡在不同阵容里价值不同（关羽在蜀国 vs 在混编阵容）；
- 完全数据驱动，**加一个羁绊 = 加一段 YAML，不写代码**。

## 2. 两种羁绊

| 类型 | 触发条件 | 例子 |
|---|---|---|
| **同场羁绊** | 己方场上同时存在指定人物集合 | 桃园结义：刘关张同场 |
| **对抗羁绊** | 敌方场上有指定人物，己方有指定人物 | 三英战吕布：敌方有吕布，己方有刘/关/张 |

### 2.1 对抗羁绊为什么值得做

这是本作最有三国味的设计：

- 它把"人物关系"变成**跨阵营的博弈**——你带吕布，对手的刘关张就更强；
- 它让对局有了"宿命感"，而不是纯粹的数值堆叠；
- 它是**对称的**（谁带谁受益/受损都明确），不会产生不公平。

## 3. 结算时机

| 时机 | 动作 |
|---|---|
| 任意人物卡入场后 | 重新检查所有羁绊条件 |
| 任意人物卡阵亡后 | 重新检查所有羁绊条件（**羁绊可能失效**） |
| 羁绊生效 | 授予对应的增益（属性修正或关键词） |
| 羁绊失效 | 移除该增益；若属性下降导致血量 ≤ 0，则触发死亡结算 |

**关键规则**：羁绊是**动态**的，不是永久标记。刘关张死了一个，另外两个立刻失去加成。

## 5. 数据格式

```yaml
- id: taoyuan
  name: 桃园结义
  type: ally            # ally = 同场羁绊 | rival = 对抗羁绊
  condition:
    require: [shu_liubei, shu_guanyu, shu_zhangfei]   # 必须全部在场（己方）
  effects:
    - target: { self: true }        # 作用于条件中的己方人物
      modify: { attack: 1, health: 1 }
  memo: "刘关张同场，三人齐涨"
```

```yaml
- id: three_heroes_vs_lvbu
  name: 三英战吕布
  type: rival
  condition:
    enemy_has: [qun_lvbu]                              # 敌方场上有
    require: [shu_liubei, shu_guanyu, shu_zhangfei]    # 己方场上有（任一即可，见 note）
  match: any                                           # any = 满足任意一个即触发
  effects:
    - target: { matched: true }
      modify: { attack: 1 }
  memo: "吕布在场，刘关张斗志更盛"
```

### 5.1 字段说明

| 字段 | 取值 | 说明 |
|---|---|---|
| `type` | `ally` / `rival` | 同场 / 对抗 |
| `condition.require` | 人物 id 数组 | 己方必须存在的人物 |
| `condition.enemy_has` | 人物 id 数组 | 敌方必须存在的人物（仅 rival） |
| `match` | `all` / `any` | 默认 `all`；`any` 表示满足任一即可 |
| `effects[].target` | 选择器 | `self`（条件人物）/ `matched`（匹配到的人物）/ `all_allies` |
| `effects[].modify` | 属性修正 | `attack` / `health` / `keywords` |

## 6. 平衡注意事项

| 风险 | 说明 | 对策 |
|---|---|---|
| 羁绊过强 | 凑齐即无敌，压缩构筑多样性 | 单个羁绊总价值控制在 2–4 属性点 |
| 羁绊失效猝死 | 属性下降导致血量 ≤ 0 | 血量不会因羁绊失效降到 0 以下，最低保留 1 点（**待确认**） |
| 对抗羁绊被滥用 | 玩家故意带弱卡触发对手羁绊？ | 对抗羁绊只加成**己方**，不影响敌方 |
| 条件过于苛刻 | 玩家永远凑不齐 | 三卡羁绊条件优先；避免 4 卡以上 |

### 6.1 羁绊失效的血量处理（待决）
