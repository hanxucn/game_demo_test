# 10 · 技能模型与状态系统

> 状态：**已定**。本文件是 `core` 规则引擎的直接实现依据。

## 1. 技能模型

所有人物卡的技能归入三类：

| 类型 | 英文 | 触发方式 | 消耗 | 典型归属 |
|---|---|---|---|---|
| **主动技** | `active` | 玩家主动使用 | 统率值 | 谋臣 |
| **触发技** | `trigger` | 满足条件自动触发 | 免费 | 武将、兵种 |
| **光环** | `aura` | 持续生效，条件满足时 | 免费 | 主公、武将 |

### 1.1 主动技

| 项 | 规则 |
|---|---|
| 使用时机 | 行动阶段 |
| 消耗 | 统率值（0–3） |
| 频率 | 每回合 1 次（默认） |
| 被震慑 | **不能使用** |
| 被混乱 | **可以使用，但目标随机**（在合法目标中） |
| 目标 | 按技能定义的选择器 |

### 1.2 触发技

| 触发时机 | 标识 | 说明 |
|---|---|---|
| 入场 | `on_play` | 打出后立即触发（俗称"战吼"） |
| 阵亡 | `on_death` | 死亡结算后触发（「忠义」「遗计」） |
| 受到伤害 | `on_damaged` | 每次受到伤害后触发 |
| 回合开始 | `turn_start` | 己方回合开始阶段 |
| 回合结束 | `turn_end` | 己方回合结束阶段 |
| 攻击时 | `on_attack` | 发起普通攻击时 |
| 被攻击时 | `on_defend` | 成为攻击目标时 |

### 1.3 光环

| 项 | 规则 |
|---|---|
| 生效条件 | 拥有者存活且条件满足 |
| 影响范围 | 按定义（自身 / 全体友方 / 特定兵种 / 特定列） |
| 重算时机 | 入场、死亡、羁绊变化后立即重算 |
| 与状态的区别 | 光环不产生"状态"，只是动态修正 |

## 2. 技能定义字段

```yaml
skills:
  - id: caochuan
    name: 草船借箭
    kind: active                # active | trigger | aura
    cost: 2                     # 仅 active
    frequency: once_per_turn    # once_per_turn | unlimited | once
    target:                     # 选择器，见 13-balance-data-model.md
      side: ally
      filter: { type: strategist }
      count: 1
    condition: {}               # 可选
    effects:
      - action: draw
        value: 2
```

## 3. 状态全集

### 3.1 增益状态

| # | 状态 | 效果 | 叠加 | 持续 | 关键时机 |
|---|---|---|---|---|---|
| 1 | **振奋** | 攻击 +N | 层数叠加 | 永久或指定回合 | 攻击结算时 |
| 2 | **急救** | 回合开始恢复 N 点生命 | 层数叠加 | 永久 | 回合开始 |
| 3 | **架盾** | 全局嘲讽（仅前军生效） | 不叠加 | 条件性 | 目标选择时 |
| 4 | **先攻** | 先结算伤害，目标阵亡则不受反击 | 不叠加 | 永久 | 伤害结算 |
| 5 | **奇袭** | 不能被指定为攻击目标 | 不叠加 | 攻击后失去 | 目标选择时 |
| 6 | **武圣** | 免疫一次伤害 | 不叠加 | 消耗后失去 | 伤害结算前 |
| 7 | **护甲** | 吸收伤害（**仅主将**） | 层数叠加 | 永久 | 伤害结算前 |

### 3.2 减益状态

| # | 状态 | 效果 | 叠加 | 持续 | 关键时机 |
|---|---|---|---|---|---|
| 8 | **震慑** | 不能普通攻击、不能使用主动技 | 不叠加 | N 回合 | 攻击声明 / 技能使用 |
| 9 | **混乱** | 普通攻击与主动技的目标**在合法目标中随机** | 不叠加 | N 回合 | 目标选择时 |
| 10 | **中毒** | 回合结束时失去 N 点生命 | 层数叠加 | 永久 | 回合结束 |
| 11 | **虚弱** | 攻击 −N | 层数叠加 | N 回合 | 攻击结算时 |
| 12 | **断粮** | 统率值上限 −N | 层数叠加 | N 回合 | 回合开始 |

### 3.3 叠加规则

| 类型 | 规则 |
|---|---|
| **数值型**（振奋/急救/中毒/虚弱/断粮/护甲） | 按**层数累加**（2 层振奋 = +2 攻击） |
| **标志型**（架盾/先攻/奇袭/武圣/震慑/混乱） | **不叠加**，只判定"存在与否" |
| 同名标志型重复施加 | 刷新持续时间，不叠加效果 |

### 3.4 震慑的具体限制

| 行为 | 是否允许 |
|---|---|
| 普通攻击 | ❌ |
| 主动技 | ❌ |
| 触发技 | ✅（被动仍生效） |
| 光环 | ✅ |
| 被攻击 | ✅ |
| 反击 | ✅（被攻击时仍会反击） |

### 3.5 混乱的具体规则

| 项 | 规则 |
|---|---|
| 影响范围 | 普通攻击、主动技 |
| 目标选择 | 在**合法目标集合**中随机（仍受架盾、同列等规则约束） |
| 无合法目标 | 该行为无法执行（不消耗统率） |
| 是否影响触发技 | ❌ |

## 4. 结算时机表（核心）

> 这张表是 `core` 的实现规范。任何卡牌效果都必须挂在以下某个时机上，不允许"任意时刻"。

| 序 | 时机 | 触发内容 | 顺序细则 |
|---|---|---|---|
| 1 | 回合开始 | 完整回合结束时双方上限 +1（≤10）；本回合统率值回满 | ADR-061 |
| 2 | 回合开始 | 抽 1 张牌 | 牌库空 → 粮尽伤害 |
| 3 | 回合开始 | 回合开始类效果 | ① 急救回血 ② 光环重算 ③ 断粮修正（作用于下回合上限） |
| 4 | 出牌 | 检查统率是否足够 | 含断粮修正后的上限 |
| 5 | 出牌 | 消耗统率值 | — |
| 6 | 入场 | 入场触发技 | 按卡牌定义的顺序 |
| 7 | 入场后 | **羁绊重算** | 检查全部羁绊，授予/移除增益 |
| 8 | 攻击声明 | 合法性检查 | ① 是否被震慑 ② 攻击次数是否用完 ③ 是否当回合入场 ④ 是否被自己人挡住 |
| 9 | 攻击声明 | 目标选择 | ① 架盾优先级 ② 同列/跨列规则 ③ 混乱时随机 |
| 10 | 伤害结算前 | 免疫判定 | 武圣 → 消耗并免疫；其他免疫效果 |
| 11 | 伤害结算前 | 护甲吸收 | 仅主将；护甲归零后剩余伤害进入下一步 |
| 12 | 伤害结算 | 先攻判定 | 有先攻方先造成伤害；若目标阵亡 → 跳过反击 |
| 13 | 伤害结算 | 造成伤害 | 攻击力 = 面板 + 振奋 − 虚弱 + 结阵（动态） |
| 14 | 伤害结算 | 反击 | 无双/先攻例外；主将不反击 |
| 15 | 伤害结算后 | 饮血回血 | 为主将恢复等量生命（≤30） |
| 16 | 伤害结算后 | 受到伤害触发技 | `on_damaged` |
| 17 | 死亡结算 | 移出战场 | 血量 ≤ 0 |
| 18 | 死亡结算 | 亡语触发 | 忠义 / 遗计 |
| 19 | 死亡结算后 | **羁绊重算** | 羁绊可能失效 |
| 20 | 回合结束 | 回合结束类效果 | ① 中毒结算 ② `turn_end` 触发技 |
| 21 | 回合结束 | 清除临时效果 | "本回合"类增益/减益 |
| 22 | 回合结束 | 手牌上限检查 | >10 张则弃至 10 张 |
| 23 | 回合结束 | 交出行动权 | — |

## 5. 交互边界（必须实现的用例）

| # | 场景 | 正确结果 |
|---|---|---|
| 1 | 有「先攻」的攻击者攻击有「武圣」的目标 | 攻击者先造成伤害 → 武圣免疫该次伤害 → 目标存活 → **目标反击**（先攻的"目标阵亡则免反击"不成立） |
| 2 | 「无双」攻击者攻击有「先攻」的目标 | 攻击者造成伤害 → 无双跳过反击 → 目标若存活仍会反击？**否**：反击属于被攻击方，无双免除的是攻击者受到的伤害，因此目标不反击 |
| 3 | 「混乱」人物攻击，场上存在「架盾」 | 在**架盾人物集合**中随机选择目标 |
| 4 | 后军的盾兵 | **失去架盾**，不再强制敌方目标选择 |
| 5 | 盾兵同时拥有「奇袭」 | **不允许共存**（会导致架盾死锁），见 §6 |
| 6 | 「结阵」步兵攻击时相邻步兵被击杀 | 按**攻击声明时**的场面判定 |
| 7 | 羁绊加成导致血量变化后羁绊失效 | 血量最低保留 1 点（**待确认**，见 `09-bonds.md` §6.1） |
| 8 | 中毒人物在回合结束前被击杀 | 不再结算中毒 |
| 9 | 「震慑」人物被攻击 | 仍会正常反击 |
| 10 | 主将被「震慑」 | 无效（震慑只作用于人物卡） |

## 6. 禁止的关键词组合

| 组合 | 原因 |
|---|---|
| 架盾 + 奇袭 | 架盾要求"必须优先攻击它"，奇袭要求"不能被指定" → 死锁 |
| 架盾 + 无双 | 不是禁止，但价值叠加过高，需严格控预算 |

> 数据校验器需在 CI 中检查非法组合（见 `13-balance-data-model.md` §校验规则）。

## 翻面（ADR-059 定稿）

| 项 | 规则 |
|---|---|
| 效果 | 被翻面的单位**当回合不能行动**（不能普攻、不能用主动技），**不能被指定为目标**（含计策） |
| 解除 | **该单位自己的下个回合开始时**翻回正面，当回合即可正常行动 |
| 表现 | 战场上显示为**卡背**；不显示攻血/技能/状态标记 |
| 用途 | 保护性（吕蒙「白衣渡江」把自己和友方翻面规避打击，下回合再行动） |

> **与"召唤失调"的区别**：召唤失调是新入场当回合不能**攻击**（仍可用技能、仍可被指定）；
> 翻面是完全不能行动**且**不能被指定。
