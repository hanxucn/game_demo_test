# 04 · 资源与节奏

> 状态：**已定**（部分数值待调）

## 1. 统率值（唯一资源）

| 项 | 规则 |
|---|---|
| 初始值 | 1 |
| 成长 | 每回合开始阶段 +1 |
| 上限 | 10 |
| 恢复 | 每回合开始阶段恢复至当前上限（**不保留上回合剩余**） |
| 用途 | 打出卡牌、使用主将主动技 |
| 类型 | 数值型，可被「断粮」等效果临时降低上限 |

### 1.1 曲线

| 回合 | 统率上限 | 该回合可做的典型操作 |
|---|---|---|
| 1 | 1 | 出一张 1 费卡 |
| 2 | 2 | 一张 2 费 或 两张 1 费 |
| 3 | 3 | 3 费武将 / 2 费 + 1 费 |
| 4 | 4 | 4 费武将 + 主公技 |
| 5 | 5 | 5 费核心卡 |
| 6 | 6 | 大牌 + 技能组合 |
| 7–10 | 7–10 | 高费武将 / 组合技爆发 |

> **设计意图**：1→10 的曲线是卡牌游戏最成熟的节奏模型，它天然产生"前期铺场、中期博弈、后期爆发"的情绪曲线。

## 2. 护甲

| 项 | 规则 |
|---|---|
| 归属 | 附加于**主将**（v1 不支持给人物卡加护甲） |
| 结算 | 受到伤害时**优先扣除护甲**，护甲为 0 后才扣生命 |
| 保留 | **永久保留**，不随回合清除 |
| 上限 | 无上限 |
| 来源 | 孙权「坐断东南」、部分战法卡 |
| 与治疗的区别 | 治疗只能恢复生命（不超过 30），不能加护甲 |

> **设计意图**：护甲是"吴"的防守标识，也是对抗"计谋直伤"的手段。

## 3. 主公生命 30 的论证

### 3.1 为什么 30 是合理的

高费武将的攻击力可以很高（例如 8），而主将保护规则要求"清空一列"才能攻击主将，因此：

```
30 HP ÷ 8 攻击 = 4 次未受阻挡的攻击
```

- 4 次攻击意味着至少 4 个回合的铺垫与破阵，节奏成立；
- 若主将可被无脑打脸（无阵型保护），对局会退化为"谁先抽到高攻武将"，30 HP 反而不够。

### 3.2 高攻武将的定位

| 定位 | 说明 |
|---|---|
| 破阵后的收割者 | 需要先清空一列，才能让高攻武将打主将 |
| 清场主力 | 8 攻可以一击秒杀绝大多数兵种 |
| 需要保护 | 高攻武将通常血不高，容易被计谋/战法针对 |

### 3.3 数值校验示例（占位，非最终设计）

以"8 费、8 攻击"的武将为例：

| 项 | 值 |
|---|---|
| 8 费白板基准 | 2 × 8 + 1 = **17 属性点** |
| 8/8 的属性点 | 8 + 8 = **16 点** |
| 剩余预算 | 1 点 |
| 「无双」的成本 | 约 −2 点 |
| 结论 | 8 费 8/8 + 无双 超模约 1 点，**可接受**；或调为 7/8 + 无双 |

> 详细定价方法见 `13-balance-data-model.md`。

## 4. 后手补偿（ADR-053）

| 项 | 规则 |
|---|---|
| 方式 | 后手方在自己**第 1 个回合**的抽牌阶段**多抽 1 张**（该回合共抽 2 张） |
| 目的 | 补偿先手优势（实测先手胜率约 54%，加补偿后约 50%） |
| 配置 | `createMatch({ secondCompensation: 'none' \| 'extra_draw' })`，默认 `extra_draw` |

> **原「传国玉玺」已删除**：设计者确认该卡非本人设计（源自本仓库初始提交的 GDD 草案，
> 原文档称其"等价于炉石的幸运币"）。它是一张 0 费、本回合统率 +1 的补偿卡。
> 另注：后手**本来就**有「起手 4 张 vs 先手 3 张」的牌差补偿，本项是在此之上追加的。
>
> **实测（各 300 局）**：无补偿时先手胜 54.0%；带玉玺时 50.0%；改为多抽 1 张时 54.3%。
> 三者差异**均在噪声范围内**（95% 置信区间约 ±11 个百分点），
> 即 300 局的样本**分辨不出这么小的效果**。因此本条保留的是**设计直觉**，不是实测结论。

## 5. 粮尽（防拖延机制）

| 项 | 规则 |
|---|---|
| 触发 | 回合开始阶段抽牌时牌库为空 |
| 伤害 | 第 1 次 1 点，之后递增（1、2、3…） |
| 目标 | 抽牌方主将（先扣护甲） |
| 计数 | 每方独立累计 |

> 详见 `03-turn-flow.md` §4。

## 6. 节奏控制清单

| 目标 | 手段 |
|---|---|
| 对局不超过 8 分钟 | 回合上限 40、粮尽、主将 30 HP |
| 避免"谁也破不了阵" | 计谋直伤 + 粮尽 + 破阵奖励 |
| 避免"3 回合速攻" | 主将需清空一列 + 架盾保护 + 1 费兵种血量 |
| 保证后期有爆发 | 统率上限 10 + 高费武将 |
