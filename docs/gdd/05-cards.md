# 05 · 卡牌总则与模板

> 状态：**已定**（人物卡的具体数值与技能**待填**）

## 1. 六类卡牌

| # | 类型 | 留场 | 有攻/血 | 说明 |
|---|---|---|---|---|
| 1 | 普通兵种卡 | ✅ | ✅ | 步兵 / 盾兵 / 弓箭手，基础单位 |
| 2 | 武将卡 | ✅ | ✅ | 以武力为主，通常有高攻或强力技能 |
| 3 | 谋臣卡 | ✅ | **攻 ≤ 1** | **不能普通攻击**，靠主动技与计略输出 |
| 4 | 事件卡 | ❌ | ❌ | 三国历史事件，**对双方同时生效** |
| 5 | 战法卡 | ❌ | ❌ | 兵书战法，单次战术效果 |
| 6 | 特殊兵种卡 | ❌ | ❌ | **进化卡**：将场上特定兵种进化为精锐 |

> **人物卡** = 类型 1/2/3（留场）；**非人物卡** = 类型 4/5/6（一次性结算）。

## 2. 卡牌字段模板

每张卡在数据文件中包含以下字段（完整 schema 见 `13-balance-data-model.md`）：

| 字段 | 必填 | 类型 | 说明 |
|---|---|---|---|
| `id` | ✅ | string | 唯一标识，如 `shu_guanyu` |
| `name` | ✅ | string | 卡名，**≤4 字**（卡面显示限制） |
| `faction` | ✅ | enum | `shu` / `wei` / `wu` / `qun` / `neutral` |
| `type` | ✅ | enum | `troop` / `general` / `strategist` / `event` / `tactic` / `elite` |
| `cost` | ✅ | number | 统率值消耗，0–10 |
| `attack` | 人物卡必填 | number | 攻击力；**谋臣上限 1**（默认预设，见 ADR-015/018）|
| `health` | 人物卡必填 | number | 生命值 |
| `keywords` | 可选 | string[] | 关键词列表，见 `06-keywords.md` |
| `skills` | 可选 | object[] | 技能定义，见 `10-skills-statuses.md` |
| `bonds` | 可选 | string[] | 参与的羁绊 id，见 `09-bonds.md` |
| `upgradeTarget` | 进化卡必填 | object | 目标兵种与进化结果 |
| `flavor` | 可选 | string | 风味文本（**不显示在卡面**，用于收藏页） |
| `memo` | ✅ | string | **一句话记忆点**（设计用，不显示） |

### 2.1 一句话记忆点规范

每张卡必须能用一句话说清"它为什么值得被记住"：

- ❌ 反例："攻击力 4，生命值 5 的武将"
- ✅ 正例："阵亡时对全体敌人造成 2 点伤害"
- ✅ 正例："只要它在场，我方弓箭手攻击 +1"

**检验方法**：玩家在抽到这张卡时，能否立刻说出它的价值。

## 3. 两条高费卡设计路线

高费卡（≥6 统率）必须选择以下两条路线之一，不允许"什么都占"：

### 路线 A：低属性 + 强技能

| 项 | 说明 |
|---|---|
| 属性 | 低于同费白板基准 |
| 技能 | 价值高、有决定性影响 |
| 代表 | 诸葛亮、周瑜、郭嘉（待填具体数值） |
| **风险** | 方差大——技能被打断就废 |
| **对策** | ① 技能可互动（需铺垫/可被震慑/可被移除）；② 提供保底小收益 |

### 路线 B：高属性 + 无技能（或少技能）

| 项 | 说明 |
|---|---|
| 属性 | 达到或略高于同费白板基准 |
| 技能 | 无，或只有一个廉价关键词 |
| 代表 | 吕布、许褚、张飞（待填具体数值） |
| **风险** | 被一张解场卡一换一 |
| **对策** | ① 给"抗解"关键词（武圣/忠义/无双）；② 靠低费铺垫与保护 |

### 3.1 为什么必须二选一

同时拥有高属性与强技能的高费卡，会在所有对局中成为"必带"，压缩构筑多样性。
若确实需要"又高又强"的卡，请将其费用提高到 9–10，或附加明确的负面代价。

## 4. 卡面 UI 元素

卡面**只显示**以下内容（横屏约 147pt × 180pt）：

```
┌──────────────────┐
│ ①统率值   ②阵营  │
│                  │
│   ③ 卡 名         │
│                  │
│   ④ 关键词图标    │
│                  │
│ ⑤攻击   ⑥生命    │
└──────────────────┘
```

| 元素 | 显示规则 |
|---|---|
| ① 统率值 | 左上角数字 |
| ② 阵营 | 右上角色块（蜀=绿 / 魏=蓝 / 吴=红 / 群=灰） |
| ③ 卡名 | ≤4 字，居中 |
| ④ 关键词图标 | 最多 3 个，超出显示"+"；点击卡牌查看详情 |
| ⑤ 攻击 | 左下角；谋臣为 0 攻时显示"—" |
| ⑥ 生命 | 右下角；受伤害后显示当前值（红色） |

**不显示**：技能描述文字、风味文本、羁绊信息（这些在点击详情面板中展示）。

## 5. 卡牌模板（供策划填写）

### 5.1 人物卡模板

```yaml
- id: shu_xxx
  name: （≤4 字）
  faction: shu
  type: general          # troop | general | strategist
  cost: 0                # 0-10
  attack: 0
  health: 0
  keywords: []           # 见 06-keywords.md
  skills: []             # 见 10-skills-statuses.md
  bonds: []              # 见 09-bonds.md
  memo: ""               # 一句话记忆点
  flavor: ""
```

### 5.2 非人物卡模板

```yaml
- id: tactic_xxx
  name: （≤4 字）
  faction: neutral       # 或具体阵营
  type: tactic           # event | tactic | elite
  cost: 0
  target: ""             # 选择器，见 13-balance-data-model.md
  effects: []            # 效果列表
  memo: ""
  flavor: ""
```

## 6. 命名与文案规范

| 项 | 规范 |
|---|---|
| 卡名 | ≤4 字；优先使用人物本名或广为人知的称号 |
| 同名冲突 | 若同一人物有多种形态，用副标题区分（如「关羽·武圣」） |
| 技能名 | ≤4 字，优先使用史书/演义中的原词 |
| 风味文本 | 引用或化用演义原文，不超过 30 字 |
| 用词统一 | 统一使用"主公/人物卡/统率值/架盾"等术语表词汇 |
