## 我盲写时怀疑的问题（需用眼睛逐条确认）

1. **背景**是 CSS 渐变拼的剪影，不是插画 → 观感廉价
2. **卡框**只有 2px 描边，没有金属倒角、宝石、纹理 → 扁平
3. **立绘**是"大字 + 渐变"占位 → 完全不像人物
4. **手牌**平铺一排，没有炉石的扇形排列与 3D 倾斜
5. **主公卡放侧边**可能是"布局丑"的主因（为 56×78 让路做的妥协）
6. **侧栏面板**（统率值/回合）是纯色盒子，没有设计感
7. **图标系统缺失**：关键词、状态全是文字 chip

---

## 对标炉石的差距清单（按观感影响力排序）

| 优先级 | 项 | 说明 |
|---|---|---|
| 1 | **插画** | 背景 + 立绘 + 卡框占观感约 70%，CSS 无法伪造 |
| 2 | **卡框细节** | 倒角、宝石、内发光、材质纹理 |
| 3 | **手牌表现** | 扇形排列、悬停放大、拖拽轨迹 |
| 4 | **字体层级** | 数字专用字体、卡名书法体（中文需子集化） |
| 5 | **动效** | 粒子、光效、缓动曲线 |
| 6 | **图标系统** | 统一风格的图标集（关键词/状态/按钮） |
