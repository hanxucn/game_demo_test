# 02 · 战场与攻击规则

> 状态：**已定**（ADR-051 改版：**一行 8 格**，取消前后排与「同列/穿透/破阵」）
>
> 本文件是整个游戏的规则地基，所有卡牌效果都在这套规则上叠加。

## 1. 战场结构

每方 **一行 8 格**（单排），主将位于本方阵型的**最远端**（阵型之后，不占格）。

> **ADR-051 改版说明**：原设计是 5 列 × 2 排 = 10 格。改为单排后，
> 「同列」「前军 / 后军」「穿透」「破阵斩将」这些概念**全部作废**——
> 攻击目标改为「架盾优先，否则自由选（含主将）」（§3）。
> 数据模型里 `back` 这一排保留为空壳，任何迭代都不会读它。

**从外到内的空间顺序**（以我方视角，屏幕从上到下）：

```
敌 主 公  →  敌 后 军  →  敌 前 军  →  ══中线══  →  我 前 军  →  我 后 军  →  我 主 公
   最远                                            最远
```

```
                          ┌──────────┐
                          │ 敌 主 公 │   ← 敌最远端
                          └──────────┘
                    ┌────┬────┬────┬────┬────┐
        敌 后 军 →  │    │    │    │    │    │
                    ├────┼────┼────┼────┼────┤
        敌 前 军 →  │    │    │    │    │    │
                    └────┴────┴────┴────┴────┘
        ══════════════════════════════════════════
                    ┌────┬────┬────┬────┬────┐
        我 前 军 →  │    │    │    │    │    │
                    ├────┼────┼────┼────┼────┤
        我 后 军 →  │    │    │    │    │    │
                    └────┴────┴────┴────┴────┘
                          ┌──────────┐
                          │ 我 主 公 │   ← 我最远端
                          └──────────┘
                    ↑    ↑    ↑    ↑    ↑
                   列1  列2  列3  列4  列5
```

**进攻路径**：我方某列的人物卡 → 该列敌方前军 → 该列敌方后军 → **敌方主公**。
因此"清空一列"= 击破该列的**前军与后军两排**，之后才能沿该列直取敌方主公。

### 坐标系统

- **列（Lane）**：1–5，从玩家视角自左向右编号；**双方的列号在屏幕上对齐**（我方列 3 正对敌方列 3）
- **排（Row）**：`前军` / `后军`
- **格（Slot）**：`(列, 排)`，例如 `(3, 前军)`
- **同列**：双方屏幕位置相同的列，即"正对面"

### 格子容量

| 项 | 规则 |
|---|---|
| 每格 | 最多 1 张人物卡 |
| 每方上限 | 10 张人物卡 |
| 空格 | 属于正常状态，空格构成"穿透"与"破阵"的基础 |

## 2. 部署规则

| 项 | 规则 |
|---|---|
| 落牌位置 | 可放在**己方任意空格**（一行 8 格） |
| 满格 | 场上无空格（8 格占满）时不能部署新人物卡 |
| 入场当回合 | **不能攻击**（「疾行」除外），但可以触发"入场"技能 |
| 入场触发 | 按"战吼/入场"结算，时机见 `10-skills-statuses.md` 结算时机表 |

## 3. 普通攻击

### 3.1 谁能攻击

| 卡类 | 能否普通攻击 |
|---|---|
| 兵种卡（步兵/盾兵/弓箭手） | ✅ |
| 武将卡 | ✅ |
| 谋臣卡 | ✅ **可以**（ADR-051 取消原「谋臣不能普攻」；谋臣默认 1 攻） |
| 主将 | ❌ 只有主动技 |
| 被「震慑」的人物 | ❌ 不能攻击，也不能使用主动技 |
| 当回合入场的人物 | ❌（「疾行」除外） |
| 已攻击过的本回合 | ❌（「连击」允许 2 次） |

### 3.2 攻击目标判定（ADR-051 改版）

按以下**优先级顺序**判定合法目标：

```
① 场上存在敌方「架盾」人物卡？
   → 目标只能是架盾人物卡（多个架盾则任选其一）★ 嘲讽
② 否则：可自由选择**敌方任意人物卡**作为目标
   （「翻面」与「奇袭」的单位不可被指定）
③ 并且：**始终可以直接攻击敌方主将**
```

> **与旧版的差别**：取消了「近战只能打同列」「前军→后军穿透」「必须清空一列才能打主将」
> 三条规则。现在主将是**随时可打的开放目标**，唯一的阻挡手段就是「架盾」。
> 这使对局节奏显著加快——主将 30 血，需要靠架盾与回复维持。

### 3.3 弓箭手「射箭」

弓箭手**默认 0 攻**，不通过普通攻击输出，而是靠「射箭」：

| 项 | 规则 |
|---|---|
| 时机 | **回合结束时**自动执行（无需玩家操作） |
| 目标 | **随机**一名敌方人物**或敌方主将**（含主将） |
| 效果 | 1 点伤害 |
| 多个弓兵 | **每个弓兵各结算 1 次**（3 个弓兵 = 3 次随机 1 伤） |

> 实现：`damage value:1` + `target.filter.include_lord: true` + `mode: random`（ADR-051 新增 `include_lord`）。
> 旧版「神射：可攻击任意列的人物卡」在单排后已无意义。

### 3.4 攻击结算顺序

一次普通攻击按以下顺序结算：

```
1. 攻击者 → 目标：造成等同于攻击者攻击力的伤害
2. 若目标为人物卡且存活 → 目标反击：对攻击者造成等同于目标攻击力的伤害
3. 例外：
   · 攻击者有「先攻」→ 先结算第 1 步；若目标阵亡，则跳过第 2 步（不受反击）
   · 攻击者有「无双」→ 跳过第 2 步（不受反击）
   · 目标为主将 → 主将不反击
4. 伤害结算（护甲/免疫/武圣等修正）→ 见 `10-skills-statuses.md`
5. 死亡结算：血量 ≤ 0 的人物卡移出战场，触发「忠义/遗计」等亡语
```

## 4. 主将保护（ADR-051 改版）

| 项 | 规则 |
|---|---|
| 攻击主将的条件 | **无敌方「架盾」人物卡在场**即可直接攻击；架盾在场时必须先清掉架盾 |
| 为什么 | 单排后没有"阵型纵深"可依托，主将保护改由**架盾**承担 |
| 主将反击 | 无 |
| 主将受伤 | 先扣护甲，护甲为 0 后扣生命 |
| 主将阵亡 | 生命 ≤ 0 → 该方立即失败 |

> **战术推论**：主将不再是"打穿一列才能碰到"，而是**默认开放**。因此：
> · 架盾单位是主将的**唯一盾牌**，价值大幅上升；
> · 回复（刘备仁德、华佗青囊）与护甲的防守价值同样上升；
> · 对局节奏比旧版快——这是 ADR-051 有意接受的取舍（设计者要求「可以直接攻击主将」）。
>
> **⚠️ 平衡风险**：8 格铺满时每回合可对主将倾泻全部攻击力（轻松 20+ 点），
> 主将 30 血可能偏薄。**需要实机测试**后决定是否上调主将血量或加回复手段（记入 Q-02-x）。

### 4.1 泄压阀

单排后主将直接暴露，节奏已经很快，因此**不再需要**旧版的「破阵奖励」：

1. **计谋直伤**：谋臣的主动技、战法卡、事件卡可以直接伤害主将
2. **粮尽**：牌库抽空后，每回合抽牌时受到递增伤害（1、2、3…）

> ~~破阵奖励（清空一列 +1 攻）~~ 已随「列」的概念一起作废。

## 5. 架盾（嘲讽，ADR-051 改版）

| 项 | 规则 |
|---|---|
| 生效条件 | 该人物卡带「架盾」关键词即生效（**不再限定前军**——单排后没有前军） |
| 效果 | 敌方任何普通攻击**必须先攻击架盾人物**；**不给出主将选项** |
| 优先级 | 最高（先于自由选目标） |
| 破盾手段 | ① 直接击杀架盾人物；② 谋臣的计略 / 战法 / 事件卡造成的伤害**不吃嘲讽** |
| 多个架盾 | 存在多个时，攻击者可**任选其一**作为目标（嘲讽不唯一） |

> **与炉石「嘲讽」一致**：架盾在场时，普通攻击既不能越过它打别的将士，也不能打主将。
> **设计意图**：单排后架盾是主将唯一的盾牌，因此它同时也是"保命"手段——
> 与旧版「架盾不阻挡打主将」相反（旧版主将靠阵型保护，新版只能靠架盾）。

## 6. 列数权衡（决策记录 ADR-001 → ADR-051 改版）

> **2026-09 ADR-051 变更**：本节讨论的「5 列 × 2 排」已改为「一行 8 格」。
> 下面保留当时的权衡记录作为决策存档。

### 背景

主将可被攻击的条件是"攻击者所在列两排皆空"。防守方要封死所有列，至少需要 **N 个单位**（N = 列数），而受统率限制，实战场上通常只有 3–6 个单位。

### 结论

| 列数 | 封死所需单位 | 节奏倾向 |
|---|---|---|
| 4 列 | 4 | 偏慢、偏控制 |
| **5 列（采用）** | 5 | **居中** |
| 6 列 | 6 | 偏快、偏铺场 |

- **采用 5 列 × 2 排**：节奏居中，配合 30 HP + 6–8 分钟目标；
- "补空列"（lane denial）成为核心技巧：1 费的 2/1 步兵不只是站场，还是堵隘口的工具；
- 6 列在横屏下 UI 同样可行，作为**可选方案**保留（若实测对局过慢可改）。

### 降级预案

若真机测试发现 5 列在部分机型上可读性不足 → 退回 4 列 × 2 排，并把主公生命降至 25 以补偿节奏。

## 7. UI 约束（横屏）

| 项 | 约束 |
|---|---|
| 方向 | 横屏（`game.json` → `deviceOrientation: "landscape"`） |
| 设计基准 | 736 × 414（微信 `displayMode: mobile`） |
| **适配策略** | **fit-height（高度铺满）+ 宽度自适应**；横向 5 列用 Widget 百分比布局，不写死像素宽 |
| 每列宽度 | 约 140pt（设计尺寸）；物理宽度随屏幕变化：iPhone SE 约 127px → iPad 约 191px |
| 卡面内容 | 卡名（≤4 字）+ 攻/血数字 + 关键词图标；**不在卡面放描述文字** |
| 关键词说明 | 长按/点击卡牌弹出详情面板 |
| 状态显示 | 图标 + 层数角标；异常状态用红色描边 |
| 列高亮 | 悬停/选中时高亮该列的合法目标 |
| **最小机型风险** | iPhone SE / 12 mini 横屏（375pt 高）下兵阵卡约 **127 × 51 px**，卡名 11.8px、数值 10.9px——可读但无余量，**必须真机验证** |
| **手牌补偿** | 最小机型手牌卡仅 56 × 65 px，需**点按放大预览** |
| 降级方案 | 若真机反馈卡面过挤 → 设计高度改 375 + 紧凑单行卡面（行高 46pt） |

> 实测数据与交互原型见 `prototype/README.md` 与 `prototype/battlefield-wireframe.html`。
