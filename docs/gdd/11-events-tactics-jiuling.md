# 11 · 事件卡、战法卡与酒令

> 状态：**草案**（机制已定，具体卡牌待策划确认）

## 1. 事件卡：「天道无情」原则

### 1.1 核心公式

> **事件卡 = 对双方同时生效的对称效果 + 施放者的时机优势**

这是本作对"事件卡"的定义，也是它区别于炉石法术的地方：

- 天灾人祸**不认敌我**（灾年、瘟疫、南蛮入侵都伤害所有人）；
- 但施放者可以选择**时机**——在自己占优、或对手关键人物残血时引爆；
- 因此事件卡是"**放大器**"，不是"解场牌"。

### 1.2 设计规则

| 规则 | 说明 |
|---|---|
| 对称性 | 基础效果对双方完全相同 |
| 时机优势 | 施放者可额外获得一个小收益（如抽 1 张、自身单位不受影响） |
| 费用 | 2–6 统率 |
| 目标 | 通常是"全场"或"某一排" |
| 不能是纯优势 | 若一张事件卡只对敌方生效，它应归类为**战法卡** |

### 1.3 事件卡草案

| # | 卡名 | 费用 | 效果 | 施放者额外收益 | 状态 |
|---|---|---|---|---|---|
| 1 | 灾 年 | 2 | 双方所有人物卡失去 1 点生命 | 无 | 草案 |
| 2 | 五谷丰登 | 3 | 双方主将各恢复 3 点生命 | 施放者抽 1 张牌 | 草案 |
| 3 | 南蛮入侵 | 4 | 双方所有**前军**人物卡受到 2 点伤害 | 无 | 草案 |
| 4 | 黄巾之乱 | 3 | 双方各召唤 2 个 1/1 黄巾兵（随机空格） | 施放者的黄巾兵获得「疾行」 | 草案 |
| 5 | 火烧洛阳 | 5 | 摧毁双方**后军**的所有人物卡 | 无 | 草案 |
| 6 | 瘟疫 | 3 | 双方所有人物卡获得「中毒 1」 | 无 | 草案 |

> ⚠️ **5 列下"行目标 = 5 个"**：`南蛮入侵`、`火烧洛阳` 这类行效果比 4 列时强 25%，费用与伤害需实测校准。

### 1.4 数据格式

```yaml
- id: event_zainian
  name: 灾年
  faction: neutral
  type: event
  cost: 2
  target:
    side: both          # 双方
    filter: { type: character }
  effects:
    - action: damage
      value: 1
  memo: "全场掉血，谁先放谁掌握节奏"
```

## 2. 战法卡

### 2.1 与事件卡的区别

| 项 | 事件卡 | 战法卡 |
|---|---|---|
| 影响对象 | 双方对称 | 单方（通常是己方或敌方） |
| 定位 | 放大器 / 节奏控制 | 战术解 / 组合技 |
| 费用 | 2–6 | 1–5 |

### 2.2 分类与草案

| 分类 | 卡名 | 费用 | 效果 | 状态 |
|---|---|---|---|---|
| **伤害** | 火 攻 | 3 | 对敌方一名人物卡造成 4 点伤害 | 草案 |
| **伤害** | 箭 雨 | 4 | 对敌方某一列的两名人物卡各造成 3 点伤害 | 草案 |
| **伤害（主将）** | 反间计 | 4 | 对敌方主将造成 4 点伤害（无视阵型） | 草案 |
| **位移** | 暗渡陈仓 | 2 | 将一名己方人物卡移动到己方任意空格 | 草案 |
| **位移** | 围魏救赵 | 3 | 将一名敌方人物卡移回其手牌（若手牌已满则改为受到 3 点伤害） | 草案 |
| **增益** | 暂避其锋 | 2 | 本回合内，一名己方人物卡受到的伤害 −2 | 草案 |
| **增益** | 背水一战 | 3 | 一名己方人物卡本回合 +3 攻击，回合结束时受到 2 点伤害 | 草案 |
| **控制** | 离间计 | 3 | 敌方一名人物卡获得「混乱 1」 | 草案 |
| **控制** | 空城计 | 3 | 敌方一名人物卡获得「震慑 1」 | 草案 |
| **资源** | 草船借箭 | 2 | 抽 2 张牌 | 草案 |
| **召唤** | 借 兵 | 2 | 在己方随机空格召唤一个 1/1 步兵 | 草案 |
| **进化** | （见特殊兵种卡） | 3 | 见 `07-troops.md` | 已定 |

### 2.3 战法卡的设计要点

| 要点 | 说明 |
|---|---|
| 提供"解场"手段 | 必须有 2–3 张能处理高攻武将的卡，否则"抽到吕布就赢" |
| 提供"计谋直伤" | 必须有 2–3 张能直接伤害主将的卡，作为破阵之外的第二条胜利路径 |
| 提供"位移" | 暗渡陈仓这类卡是 5 列网格的专属价值 |
| 不做"无条件清场" | 全场清场会让对局节奏崩塌 |

## 3. 酒令（招牌机制）

### 3.1 规则

| 项 | 规则 |
|---|---|
| 选择时机 | 开局，双方各选 1 个（三选一） |
| 持续时间 | 整局 |
| 是否可见 | 双方互相可见（信息透明） |
| 解锁方式 | 成就/进度解锁，**不进入付费墙** |
| 数量 | v1 提供 4–8 个 |

### 3.2 酒令草案

| # | 酒令 | 效果 | 定位 |
|---|---|---|---|
| 1 | **温酒斩华雄** | 你打出的第一张武将卡统率消耗 −1（最低 0） | 前期节奏 |
| 2 | **对酒当歌** | 每回合首次抽牌时额外抽 1 张，然后弃 1 张 | 手牌质量 |
| 3 | **青梅煮酒** | 每回合第一次受到的伤害 −1 | 防守 |
| 4 | **煮酒论英雄** | 开局获得一张本阵营史诗卡，第 5 回合起可用 | 后期爆发 |

### 3.3 设计要点

| 要点 | 说明 |
|---|---|
| 每个酒令都要"有代价或有限制" | 否则会出现"唯一最优解" |
| 不与付费绑定 | 避免 pay-to-win 与合规风险 |
| 效果必须可读 | 玩家能一眼看出它如何影响这局 |
| 数量控制 | v1 只做 4 个，后续通过版本更新扩展 |

### 3.4 数据格式

```yaml
- id: jiuling_wenjiu
  name: 温酒斩华雄
  effects:
    - action: cost_modifier
      target: { filter: { type: general }, limit: 1 }
      value: -1
  memo: "第一张武将更便宜"
```
